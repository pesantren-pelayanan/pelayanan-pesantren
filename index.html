Layanan Desa

Apa yang bisa dibantu?

Pilih layanan, isi formulir pengajuan, dan simpan nomor pengajuan Anda. Admin desa akan memprosesnya — untuk dokumen adminduk, pemrosesan resmi dilakukan melalui kanal Disdukcapil Kabupaten Pemalang.

Cara Mengajukan

Empat langkah mudah

1

Pilih layanan

Klik kartu layanan, baca syaratnya, lalu tekan tombol ajukan.

2

Isi formulir

Nama, NIK, nomor HP/WA, dan alamat. Tidak perlu buat akun.

3

Admin memproses

Admin desa memeriksa berkas dan memprosesnya ke kanal resmi bila perlu.

4

Unduh dokumen

Begitu status Selesai, unduh dokumen Anda sendiri dari menu Lacak.

Penting: Penerbitan dokumen resmi (akta, KK, KTP, KIA) diproses oleh admin desa melalui kanal resmi Disdukcapil Kabupaten Pemalang. Website ini adalah portal layanan Desa Pesantren untuk pengajuan dan pengunduhan dokumen.
Semua Layanan

Daftar layanan Desa Pesantren

Klik salah satu layanan untuk melihat syarat dan cara mengajukan. Layanan adminduk diteruskan admin desa ke Disdukcapil; surat desa diterbitkan di tingkat desa.

Lacak Permohonan

Cek status pengajuan Anda

Masukkan nomor pengajuan (contoh: PSN-2026-000001) dan NIK yang dipakai saat mengajukan.

Login Admin Desa

Khusus perangkat desa. Akun awal: admin / admin123 — segera ganti password setelah login pertama lewat menu Pengaturan.

Dashboard Admin

Permohonan Warga

Kelola permohonan warga: ubah status, beri catatan, dan upload dokumen jadi agar warga bisa mengunduh mandiri.

Ingat: bila masih memakai password awal admin123, segera ganti lewat tab Pengaturan.
